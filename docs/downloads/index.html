iPhone / iPad

当前提供主屏幕网页应用，没有 IPA 安装包。首次联网打开并缓存后可离线使用。

  1. 用 Safari 打开筑账网页版。
  2. 点击“分享”，选择“添加到主屏幕”。
  3. 从主屏幕图标打开，先新建测试项目并验证备份。
打开网页版
换设备前，先备份。

网页、手机和电脑的账本各自独立，不会自动同步。先在旧版本“备份与共享”导出完整 ZIP，再导入新版本。卸载安卓应用、清除应用数据或清理浏览器数据可能删除账本。

这个版本仍需手动录入发票；到期提醒通过页面预警或导出日历执行，没有后台微信推送。

安装包为熟人试用预览版，Windows 尚未做商业代码签名，Mac 未公证。如系统阻止安装，请先用网页版。下载来自 GitHub，国内网络速度因线路而异。
